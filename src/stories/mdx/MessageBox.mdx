# MessageBox

---

**메시지박스** (`aa-message-box`) 컴포넌트입니다. <br />
메시지박스는 정적 함수인 `show` 함수를 통해 메시지박스를 모달 형태로 출력할 수 있습니다.<br />
`show` 함수는 `Promise`를 반환하므로 `await` 키워드를 사용하여 메시지박스의 결과를 받을 수 있습니다.

<br />

## 기본 사용법

메시지박스는 `<ad-message-box>` 컴포넌트를 DOM에 추가하여 하는 방식이 아닌, `show` 함수를 통해 모달 형태로 출력합니다.<br />
`show` 함수는 `Promise`를 반환하므로 `await` 키워드를 사용하여 메시지박스의 결과를 받을 수 있습니다.<br />
함수 호출 시 위 지원 속성의 Property 항목들을 JSON 형태로 전달하여 메시지박스를 출력할 수 있습니다.

<Source language="javascript" code={`
document.addEventListener('DOMContentLoaded', async () => {
  const result = await MessageBox.show({
    icon: 'none', // 아이콘 미출력
    title: '', // 타이틀 미출력
    message: '조회가 완료되었습니다.',
    buttons: 'ok', // 확인 버튼만 출력
  });

  if (result.state === 'ok') {
    // 확인 버튼을 클릭했을 때의 로직
  }
});
`} />

### 클릭 된 버튼 유형을 확인

`show` 함수를 통해 반환되는 `Promise` 객체의 `state` 속성을 통해 클릭된 버튼의 유형을 확인할 수 있습니다.

<Canvas of={MessageBoxStories.ClickedButton} layout="fullscreen" sourceState="none" />

<Source language="javascript" code={`
document.addEventListener('DOMContentLoaded', async () => {
  const result = await MessageBox.show({
    icon: 'question',
    title: '저장',
    message: '저장하시겠습니까?시간이 많이 걸릴 수 있습니다.',
    buttons: 'yesno',
  });

  if (result.state === 'yes') {
    // 예 버튼을 클릭했을 때의 로직
  } else if (result.state === 'no') {
    // 아니오 버튼을 클릭했을 때의 로직
  }
});
`} />

### `close` 이벤트

메시지박스가 닫힐 때 발생하는 이벤트입니다.

<Source language="javascript" code={`
const messageBox = document.querySelector('aa-message-box');

messageBox.addEventListener('close', (event) => {
  console.log(\`\${event.state} 버튼의 클릭으로 메시지박스가 닫혔습니다.\`);
});
`} />
