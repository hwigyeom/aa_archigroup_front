# Loading

---

**로딩** (`aa-loading`) 컴포넌트입니다. <br />
로딩 컴포넌트는 정적 함수인 `show` 함수를 통해 로딩을 출력하고, `hide` 함수를 통해 로딩을 제거합니다.

<br />

## 로딩 레이아웃

<Source language="html" code={`
<aa-loading message="로딩중입니다."></aa-loading>
`} />

<Canvas of={LoadingStories.Layout} layout="centered" sourceState="none" story={{ height: 180, inline: false}} />

### 지원 속성

<ArgTypes of={LoadingStories.Layout} />

<br />

---

<br /><br />

## 기본 사용법

<Source language="javascript" code={`
// 로딩 출력
Loading.show('로딩중입니다.');

// 3초 후 로딩 제거
setTimeout(() => {
  Loading.hide();
}, 3000);
`} />

## 컴포넌트 제공 함수

<br />

### `show` 함수

새로운 로딩을 모달 형식으로 출력합니다.

<Source language="javascript" code={`
Loading.show('로딩 메시지');
`} />

<PureArgsTable rows={{
  message: { name: 'message', description: '출력할 로딩 메시지 _(생략 가능)_', table: { category: 'Arguments', type: { summary: 'string' }, defaultValue: { summary: '' } } }
}} />

<br /><br />

### `hide` 함수

현재 출력된 로딩을 제거합니다.

<Source language="javascript" code={`
Loading.hide();
`} />
